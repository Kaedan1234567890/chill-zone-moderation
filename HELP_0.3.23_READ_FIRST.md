# Moderation 0.3.23 — /help readability update

- `/help` and `/czhelp` now display all help categories, with one command per line, rather than only general commands.
- Staff sections appear in the complete list only when the caller meets the existing permission requirements.
- `/help general`, `/help teleportation`, `/help lifesteal`, `/help pvp`, `/help moderation`, `/help admin`, and `/help owner` remain available as before.
- Combined command rows were split into individual rows.
- No changes to teleport, combat, moderation, or other game mechanics.
